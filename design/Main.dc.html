01  —  The gap

USDCx hides the middle. The ends still talk.

A shielded transfer between two private accounts reveals nothing. But value has to enter and leave. Every mint, every burn, every bridge exit lands on a public ledger carrying an amount, a timestamp and a destination — and a pay-run that repeats every Friday is a signature long before anyone touches the cryptography.

Three weeks of the same run and the two ends line up on amount and cadence. That correlation is the leak — not the transfer in between.
02  —  The flow

Cero sits on the flow, not beside it.

01

Score

Before anything leaves the private side, Cero simulates the exit against the live anonymity set and returns how identifiable the run would be.

POST /runs/:id/score
→ { uniqueness, set_size, window }
02

Route

Policy picks the quiet path — split the run into tranches, hold it to a dense window, or move the value through a different exit entirely.

max_uniqueness 25
split ≤8  ·  window 09:00–17:00
03

Disclose

After settlement each reviewer opens a viewing key scoped to their slice — this week’s run, not the network.

key controller@acme
scope org.runs  ·  ttl 90d
03  —  Scoped disclosure

Three people open the same run. None of them see the same page.

A viewing key is not an explorer link. It resolves one scope — a period, a program, a flagged payment — and everything outside it is not decrypted, not fetched, not there.
